# Site content

This folder holds phpolars' content for phpolars.phpstats.org. The site reads
`site.json` and the files it lists at a pinned commit, and it reads the rendered
docs HTML next to each `.qmd` in `docs.nav`.

- `benchmarks/*.json` and `verifications/*.json` are generated by
  `scripts/site-content`, in the format of phpstats.org's
  `docs/evidence-records.md`. Benchmarks are published from the Linux bench VM
  only; `read-group-join` needs uv for py-polars and peakmem, and takes a few
  minutes. `csv-pipeline` comes from `bench/csv-pipeline/run.php`.
- `evidence_gaps` names what no record measures or checks yet.
- `examples` lists the pages in the docs' Examples section, in nav order. Each
  page is `docs/examples/<slug>.qmd`, and its code and output come from
  `docs/examples/<slug>.php` through `scripts/docs-examples`.
