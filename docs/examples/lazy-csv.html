Query a large CSV file lazily

Filter and aggregate a CSV file with a lazy query, so that Polars can push the column selection and the filter into the CSV reader.

Requires the phpolars extension (Getting started). Runnable scripts: lazy-csv.setup.php and lazy-csv.php.

NoteMake the input file

The setup script writes orders.csv, one million orders in six columns (53 MB), to the current directory. It stops if the file already exists.

use Phpolars\DataFrame;
use function Phpolars\{col, int_range};

if (file_exists('orders.csv')) {
    fwrite(STDERR, "orders.csv already exists.\n");
    exit(1);
}

$id = col('order_id');
(new DataFrame(['i' => [0]]))
    ->select(int_range(0, 1_000_000)->alias('order_id'))
    ->withColumns(
        $id->mod(4)
            ->replaceStrict(
                [0, 1, 2, 3],
                ['north', 'south', 'east', 'west'],
                returnDtype: 'String',
            )
            ->alias('region'),
        $id->mul(7919)->mod(5000)->alias('customer_id'),
        $id->mul(104729)->mod(100_000)->truediv(100)
            ->alias('amount'),
        $id->mul(31)->mod(7)->eq(0)->alias('returned'),
        $id->cast('String')->str()
            ->replace('^', 'note for order ')
            ->alias('note'),
    )
    ->writeCsv('orders.csv');
use function Phpolars\{col, len, scan_csv};

$query = scan_csv('orders.csv')
    ->filter(
        col('amount')->gt(500)
            ->and(col('returned')->not()),
    )
    ->groupBy('region')
    ->agg(
        len()->alias('orders'),
        col('amount')->mean()->round(2)->alias('mean'),
    )
    ->sort('region');

echo $query->explain(), "\n\n";
echo $query->collect();
SORT BY [col("region")]
  AGGREGATE[maintain_order: false]
    [len().alias("orders"), col("amount").mean().round().alias("mean")] BY [col("region")]
    FROM
    simple π 2/2 ["region", "amount"]
      Csv SCAN [orders.csv]
      PROJECT 3/6 COLUMNS
      SELECTION: (col("amount") > 500.0) & col("returned").not()
      ESTIMATED ROWS: 1481549

shape: (4, 3)

│ region ┆ orders ┆ mean   │

│ str    ┆ u32    ┆ f64    │
╞════════╪════════╪════════╡
│ east   ┆ 107143 ┆ 750.0  │
│ north  ┆ 107133 ┆ 750.0  │
│ south  ┆ 107142 ┆ 749.99 │
│ west   ┆ 107141 ┆ 750.01 │
└────────┴────────┴────────┘
  • PROJECT 3/6 COLUMNS: the reader converts only three columns to values. It still reads and splits every line of the file.
  • SELECTION: the filter runs during the scan, so rejected rows never reach the aggregation.
  • ESTIMATED ROWS is the planner’s estimate, not a count.
  • scan_csv() doesn’t open the file. A missing file raises an error at explain() or collect().
  • read_csv() would parse all six columns of every row before filtering.
  • collect(engine: 'streaming') runs the query in batches, which can lower peak memory on large files.
