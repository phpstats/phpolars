DataFrame and LazyFrame

DataFrame holds data in memory and runs each operation immediately. LazyFrame records operations and runs them, optimized, on collect(). Both have the same verbs; a DataFrame builds each verb on a lazy query and collects it, as py-polars does.

Creating data frames

$df = new DataFrame(['a' => [1, 2], 'b' => ['x', 'y']]);          // columns
$df = new DataFrame([['a' => 1, 'b' => 'x'], ['a' => 2, 'b' => 'y']]);  // rows
$df = DataFrame::fromRows([[1, 'x'], [2, 'y']], schema: ['a' => 'Int32', 'b' => 'String']);
$df = new DataFrame(['a' => new Series('a', [1, 2])]);
$df = read_csv('data.csv');
$lf = $df->lazy();      // or scan_csv(), scan_parquet(), ...

A schema argument names columns and sets their types.

Joins

join() takes on, or leftOn and rightOn, and how: inner, left, right, full, semi, anti, or cross. suffix names clashing right-hand columns, coalesce merges key columns, nullsEqual lets null keys match, and maintainOrder (none, left, right, left_right, right_left) fixes the row order.

$sales = read_csv('sales.csv')->select('id', 'store', 'units')->head(6);
$stores = read_csv('stores.csv')->filter(col('store')->ne('S2'));

echo $sales->join($stores, on: 'store', how: 'left', maintainOrder: 'left'), "\n";
echo $sales->join($stores, on: 'store', how: 'anti'), "\n";
echo $stores->rename(['store' => 'shop'])->join($sales, leftOn: 'shop', rightOn: 'store', how: 'inner')->height(), " matched rows\n";

Iterating over groups

A GroupBy works with foreach, as py-polars’ does. The key is a list of the group’s key values, and the value is the group’s rows as a DataFrame:

foreach ($sales->groupBy('store', maintainOrder: true) as $key => $rows) {
    echo $key[0], ': ', $rows->height(), "\n";
}

Time series

groupByDynamic() groups rows into fixed time windows, and rolling() gives each row a window that ends at it. joinAsof() matches each row to the nearest earlier (or later, or nearest) row of another data frame, optionally within by groups and a tolerance. Durations are py-polars strings such as '1d', '2h30m', '1w', and '1mo'. Expressions add the rolling*By() family and ewmMean(). The functions date_range() and datetime_range() build calendars.

$daily = read_csv('sales.csv', tryParseDates: true)
    ->groupBy('date')->agg(col('units')->sum())
    ->sort('date');

// Weeks starting on Monday.
echo $daily->groupByDynamic('date', every: '1w')->agg(col('units')->sum()->alias('week_units'))->head(3), "\n";

// The seven days ending at each row.
echo $daily->withColumns(col('units')->rollingSumBy('date', '7d')->alias('last_7d'))->head(4), "\n";

// The list price in force on each day.
$prices = (new DataFrame(['from' => [new DateTimeImmutable('2024-01-01'), new DateTimeImmutable('2024-01-05')], 'list_price' => [5.0, 5.5]]))
    ->cast(['from' => 'Date']);
echo $daily->head(4)->joinAsof($prices, leftOn: 'date', rightOn: 'from');

$long = $wide->unpivot(index: 'id', variableName: 'quarter', valueName: 'sales');
echo $long, "\n";
echo $long->pivot('quarter', index: 'id', values: 'sales'), "\n";
