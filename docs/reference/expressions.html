Expressions

An Expr describes a computation on columns. Expressions are built with col(), lit(), when(), and the other functions below, and are evaluated by frame verbs such as select(), withColumns(), filter(), and agg(). They never hold PHP closures, so Polars runs them on its own threads.

Operands of comparison and arithmetic methods may be an Expr or a PHP value. PHP strings there are string literals.

Windows and order

over() evaluates an expression within groups and maps the result back to every row. orderBy sets the order for order-dependent expressions such as cumSum() and shift().

$sales = read_csv('sales.csv', tryParseDates: true)->filter(col('store')->eq('S1'))->head(8);

echo $sales->select(
    'date',
    'product',
    'units',
    col('units')->sum()->over('product')->alias('product_total'),
    col('units')->cumSum()->over('product', orderBy: 'date')->alias('running'),
    col('units')->shift()->over('product', orderBy: 'date')->alias('previous'),
    col('units')->rank('dense', descending: true)->alias('rank'),
);

Selectors

Selectors pick columns by type, name, or position, as py-polars’ polars.selectors does. They live in the Phpolars\cs namespace, so use Phpolars\cs; makes them read like py’s cs.numeric(). A selector is an Expr. or(), and(), xor(), sub(), and not() combine two selectors as sets. PHP reserves list, array, and empty, so those selectors are named list_(), array_(), and empty_().

use Phpolars\cs;

$sales = read_csv('sales.csv', tryParseDates: true)->head(3);

echo $sales->select(cs\numeric()->sub(cs\by_name('id'))), "\n";
echo $sales->select(cs\string()->or(cs\date())), "\n";
echo $sales->withColumns(cs\float()->round(0)->name()->suffix('_rounded'))->select(cs\ends_with('price', '_rounded'));
