Series

A Series is one named column. Its methods never change it in place.

  • Aggregations return a PHP value: sum(), mean(), median(), min(), max(), std(), count() (non-null values), nullCount(), nUnique(), and len(). They skip nulls, so sum() over [3, null, 1] is 4 and count() is 2.
  • Element-wise and reordering methods, such as add(), sort(), unique(), and cumSum(), return a new Series.
  • The str(), dt(), list(), and struct() namespaces work on a Series and return a Series.
  • toList() returns the values as a PHP list, converted as Types and values describes.
$s = new Series('units', [3, 1, null, 7, 4]);

echo $s, "\n";
var_dump($s->sum(), $s->mean(), $s->nullCount(), $s->dtype());
print_r($s->fillNull(0)->sort(descending: true)->toList());
print_r($s->gt(2)->toList());

In the signatures, = null marks an optional argument. Leaving it out, or passing null, uses Polars’ default for that argument, which in most cases is py-polars’ default. A note after a signature describes behavior that is easy to misread.
